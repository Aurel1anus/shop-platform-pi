# 原始语料和评测输入

本目录完整复制了原仓库 quality/data，未修改内容。

- ecommerce_agent_dataset：294 个商品 JSON、商品图片；JSON 保留完整商品介绍、SKU、FAQ 和评价，FAQ 共 827 对。
- eval：8 个 JSONL、共 477 条；其中 RAG 召回 300、意图 101、非导购意图 30、多轮记忆 10、端到端 8+20、无库存 5、图片搜索 3。

原始语料并非全部经过事实审核，部分为公开测试数据整理。FAQ 与商品说明可作为 RAG 原文，但不能把字段名 official_faq 当作官方认证。

旧评测 runner 绑定旧 Agent API 与 trace 格式，未复制为可执行脚本。新 harness 实现后再适配输入与评分，避免将 501 接口当成已接通的评测。旧 chunk ID 需映射到新来源或商品 ID。

## 第一阶段固定只读验收

项目根目录运行：

```bash
npm run check:commerce:live
```

前提：Node.js 22.19+、Python 3.10+、已安装 npm 依赖，Go API 与 MySQL 正在运行，使用含 p_002 及至少两个商品的开发演示库。默认服务地址 http://127.0.0.1:8081/api/v1，可用应用环境变量 COMMERCE_API_BASE_URL 覆盖；Python 解释器可用 COMMERCE_PYTHON 指定。命令不启动服务、不导入数据、不写业务数据、不请求模型、不需要模型凭证。

该命令先运行现有 Python 单元测试和工具到模拟 HTTP 的离线联调，再用 readonly-smoke.test.mjs 执行真实 pi 工具→TS→Python→Go→MySQL 链路。预期全部通过、退出码为 0；服务未启动、演示数据缺失或断言失败都会产生非零退出码，不跳过后假装通过。

固定场景从旧数据的“查询/详情”和“无候选”意图改编，补充当前 API 的边界检查。使用开发演示商品及工具字段断言，不沿用旧商品名称、回答关键词或 trace；未修改原 JSONL，也不代表已运行旧 477 条评测。

| 固定场景 | 来源或补充理由 | 验收依据 |
|---|---|---|
| 查询→详情→规格 | agent_e2e_queries.jsonl 的 agent_e2e_002 查询意图、agent_e2e_20_scenarios.jsonl 的 agent20_002 详情意图 | Camera 查询得到 p_002；详情名称/价格与列表一致；SKU 属于该商品，保留价格和库存 |
| 商品翻页 | 当前分页 API 补充 | 每页一条，两页商品 ID 不同，总数一致 |
| 无匹配 | agent_no_inventory_cases.jsonl 的 noinv_toilet_001 无候选意图 | 用固定无匹配标记替换品类词，items=[]、total=0 |
| 商品不存在 | 当前详情 API 补充 | 固定缺失 ID 明确失败，不返回商品 |
| SKU 空页 | 当前后端语义补充 | 越界页为空但 total 保留；缺失商品规格为空且 total=0，不据此判定不存在 |

HTTP 500、断连、无效 JSON、归属错误、超时和取消由同一命令前半部分的模拟 HTTP 联调验证。真实服务部分不会停止服务或改动数据来制造故障。价格与库存以运行时返回为准，测试不锁死金额或库存数量，也不要求同一商品的不同 SKU 价格一致。

## 首次基线：2026-10-27

实际执行 npm run check:commerce:live：18 个 Python 测试、11 个模拟 HTTP 联调子用例、5 个真实服务子场景全部通过。真实快照：p_002 / Y Camera Max，详情价格 3499.00；sku_002 / 标准版，规格价格 3499.00、库存 32、规格总数 1。此快照仅为本次观测值，不是客户端内置数据或永久期望值。

本轮未调用模型。本轮之前的模型单次链路已实际观察到 list_products→get_product→list_product_skus，并正确报告该商品及标准版 SKU；这不等于上述所有固定场景都已通过模型验收。

模型验收需要在同样的服务前提上配置模型凭证，再执行 npm run chat。例如：

```bash
npm run chat -- "先查询 Camera 的商品列表，再用实际返回的商品 ID 查询详情和规格，报告真实名称、价格及库存"
```

观察实际工具调用，再核对最终回答与工具返回一致。无匹配应如实说明，工具失败不得编造价格；不能仅检查模型是否说了“查询成功”。固定场景的批量模型评分仍未实现，本次不新增模型循环或评测框架。
